# HeritageVoice

An AI demo language learning resource for people who were born with African and Caribbean heritage and have access to their country's language on their own terms.

- **Problem it solves:** Languages going extinct and the loss of culture passing down to new generations
- **What the resource does:** Allows people who have limited access to their family's language to be able to finally learn it.
- **Why it was built:** In order to bring the confidence and joy back to learning your culture and being able to connect with family.
- It started because I wasn't able to fully connect with my family members because of the language barrier and learning a language from family can be tough. The language my family speaks is not easily accessible online and my family members do not have the time to sit and teach me. I also don't have the money to go to the country to learn so I took matters into my own hands by creating this web app.
- **When it started:** Started during my time at the Vanguarde Train & Earn Program in 2026. During a lesson, I created the idea of this web app and started drafting my own ideas and the prototype on Figma. The program showed me how I can use AI tools and my own knowledge and skills to build my idea into a MVP in less than 3 weeks.
- **Original ideas of this system are from me. Only the code is AI generated with some original code to fulfill the requirements of the program assignment**
